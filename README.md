# The First Hospitality Group — The First

Staff operating system for the four restaurants of The First Hospitality Group, New York.
Everyone knows what to do, what we serve and how we work.

- Start here: `EMPEZAR.md` (Spanish) and `CLAUDE.md` / `AGENTS.md` (agent rules).
- Source of truth: `docs/BLUEPRINT.md`, decisions in `docs/adr/`, log in `docs/DEVLOG.md`.
- Brand: `docs/brand/` (TFHG monogram, tokens, guide, board).
- Clickable prototype: open `prototype/index.html` in any browser (works offline, demo data).
- Built from scratch on the OSCURA NYC technical base: `docs/MIGRATION-FROM-OSCURA.md`.
