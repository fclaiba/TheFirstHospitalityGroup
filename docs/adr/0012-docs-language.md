# ADR 0012: Repository docs in English, owner documents in Spanish

- **Date:** 2026-10-13
- **Status:** accepted

## Context
OSCURA kept code and docs in English because the product is sold internationally and NY collaborators read them. The studio works in Spanish.

## Decision
Code, blueprint, ADRs, devlog, runbooks and agent rules in English. `EMPEZAR.md`, the commercial proposal, the market study and the master prompt in Spanish.

## Alternatives considered
| Option | For | Against |
|---|---|---|
| All Spanish | Easier for the studio | NY developers and the client's IT cannot follow |

## Consequences
Agents write devlog entries in English.
