# ADR 0022: Confirmation of schedule and menu changes

- **Date:** 2026-10-13
- **Status:** accepted

## Context
"Nobody told me" applies to the schedule and to the menu. Rules and announcements already had confirmations; the schedule and menu did not.

## Decision
Each published schedule version and each new or changed menu item must be confirmed ("I saw it") by the people it concerns before their next shift; reminders and a manager list cover the rest. An optional menu quiz can be required for promotions to server and above.

## Alternatives considered
| Option | For | Against |
|---|---|---|
| Read receipts only | No friction | Opening a screen is not a commitment |
| Signed acknowledgments | Strong record | Heavy for a daily flow |

## Consequences
Confirmation rates are success metrics and appear on the owner dashboard.
